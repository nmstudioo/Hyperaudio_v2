03

Quick start

  1. Pick the correct device profile. Use v5-HD for KZ EDX Pro and V6 for the Redmi 12 speaker. Keep each release separate and review its file-pairing notes; the IEM EEL2 header needs independent verification.
  2. Set the host to 48 kHz and verify the running rate. Set convolver preamp to 0 dB for the IEM chain.
  3. Turn off other processing: extra EQ, bass enhancement and OEM sound effects.
  4. Load in order: DDC (.vdc), then Convolver (.irs), then Liveprog (.eel).
  5. Start at low volume and confirm the profile and processing mode.

Evidence boundary. PASS denotes static file-format, coefficient, or source-structure checks only. It does not mean native RootlessJamesDSP, ARM, device, acoustic or listening validation. No current selected profile has been marked device- or listening-validated.

Known limitationsSeven documented caveats
  • Reproducibility. iem_build.py, generate_irs.py and the source inputs are not included, so the IRS cannot be regenerated from this repository alone.
  • Speaker IRS provenance. The measurement setup is not documented. Any microphone response in the source measurement is also in the filter.
  • Target provenance. Retained response plots are context, not proof of the selected release or a calibrated acoustic result.
  • Runtime compatibility. Native RootlessJamesDSP, Android/ARM and target-device tests have not been run for these selected files.
  • EEL2 pairing. The IEM v5-HD EEL2 header names an earlier Ultra IRS/VDC pair and must be independently verified before use.
  • Limiter scope. Sample-peak limiting is not true-peak limiting or driver-excursion protection.
  • Sample rate. The IRS assets are 48 kHz only. Another host rate changes timing and frequency behaviour.
10

Raw and target curves

Each correction is fitted against a target curve, in dB relative to 1 kHz. Both targets are custom, built offline, and not published standards. Listening results outrank the curves.

Raw vs target curvesTap a chart to enlarge

Method and principles: Raw and target curves.

  • Trust broad shape over narrow detail, especially on a single-position speaker measurement.
  • Never correct an artifact such as a coupler resonance or a room effect.
  • Never boost where the device has no output. The speaker has almost nothing below 100 Hz.

Documentation

Deployment guideLoad into RootlessJamesDSP

Chain: DDC (VDC) → Convolver (IRS) → EEL2 → Output. Set the host sample rate to 48 kHz. The IEM v5-HD VDC contains 14 tonal biquads; the Redmi 12 V6 VDC is identity. The IEM EEL2 header references an earlier Ultra pair and needs independent runtime verification.

The IEM v5-HD VDC and IRS both contribute to its correction chain. The Redmi 12 V6 VDC is an identity bank and its IRS provides the tonal correction. Do not add a duplicate external EQ.

Evidence & limitationsWhat has and has not been verified

The current release checks are static file and coefficient checks. Native RootlessJamesDSP execution, ARM behavior, acoustic measurements and controlled listening tests have not been performed for these selected files. The IEM v5-HD EEL2 header pairing remains a specific compatibility caveat.

The browser checks on this page are file checks, not RootlessJamesDSP runtime validation.
