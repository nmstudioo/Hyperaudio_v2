# HyperAudio · EEL2 Reference

This document outlines the rules for writing EEL2 scripts for the James34602 VM (used by RootlessJamesDSP) and defines the architecture of the HyperAudio limiter scripts.

---

## Overview

EEL2 (Expression Evaluation Language) is a lightweight scripting language used in the Liveprog module of RootlessJamesDSP. It allows for real-time, sample-by-sample digital signal processing.

Within HyperAudio, the EEL2 scripts handle dynamic safety (limiting), driver protection, and optional analog character.

---

## VM Constraints

The James34602 VM is highly optimized but features a strict parser and limited memory management. Violating these rules will cause the script to fail silently, output silence, or crash the app.

| Rule | Description |
|---|---|
| **No `@slider`** | All UI control must happen via variables declared at the top and managed in `@init` and `@sample`. |
| **Explicit Defaults** | Every slider variable MUST be reassigned its default value inside `@init`. If omitted, the UI will fail to render. |
| **Bounded sample-time loops** | EEL2 supports both `loop(count, code)` and `while(condition) (code)`. Prefer counted loops for fixed-size work, and ensure any condition loop has a strict, small upper bound when used in `@sample`. |
| **Bounded CPU** | Avoid large or data-dependent scans in `@sample`. Keep per-sample work predictable; longer fixed scans can cause audio-thread underruns on slower devices. |

## Syntax Examples

### Slider Declaration and Initialization

```eel
desc: Example Script

// Declare sliders with min/max/step
preGain10:0<-120,120,1>Pre Gain x10 dB
ceilDb10:-5<-60,0,1>Limiter Ceiling x10 dBFS

@init
// MANDATORY: Reassign defaults
preGain10 = 0;
ceilDb10 = -5;

// Derived values
preLin = pow(10, preGain10 / 200);
ceilLin = pow(10, ceilDb10 / 200);
```

The Input Guard

Always protect the DSP from invalid floating-point numbers (NaN or Infinity) generated by the Android audio system.

```eel
@sample
// If the absolute value is not less than 1e6, set to 0
!(abs(spl0) < 1e6) ? ( spl0 = 0; );
!(abs(spl1) < 1e6) ? ( spl1 = 0; );
```

HyperAudio Limiter Architecture

The shipped limiter (EDX_Limiter_v1.eel) uses a true look-ahead architecture with an O(1) CPU footprint.

1. Delay Line: The incoming signal is written to a circular buffer.
2. Peak Detection: The script calculates the instantaneous gain required to keep the peak below the ceiling.
3. Smoothing: Instant attack, exponential release.
4. Output: The delayed signal is read from the buffer and multiplied by the smoothed gain.

> [!NOTE]
> Counted loops and condition loops are part of the upstream EEL2 language. The V6 limiter uses a bounded `while` loop only while rebuilding a 49-entry suffix-minimum block; that work runs once per block, not as a 49-entry scan on every sample. Confirm real-time behavior on the target Android device before relying on it.
